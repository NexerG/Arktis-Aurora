## What changed
- `.tex` files open in the note editor as LaTeX source: `TexSourceFormat.Read(text, name, language = "latex")` → `<Document>` of `<Block StylingType="Code" Language="latex" Wrap="true">`, one per line (one trailing `\r` stripped per line); `Write(document, newline)` is the inverse.
- `RichTextDocument`: `.tex` is `FileKind.Tex` in `FileTypes` (was `extensions`, see [[axml-file-types]]); fields `sourceNewline` (`"\r\n"` if the file contains CRLF, else `"\n"`) and `sourceBom`; `LoadSource(path, "latex")` (was private `TexSource`; generic since [[xml-editor]], which sets `sourceLanguage`) reads bytes and detects a UTF-8 BOM; `Save` writes source text with `new UTF8Encoding(sourceBom)` when `sourceLanguage` is set (the `.tex` case kept) — a save is byte-identical.
- `DocumentEditorControl.LoadDocument`: `.tex` sets `document.layout.page = new PageLayout { mode = PageMode.Pageless }`; `content.plainText` is true for `.txt` and `.tex` (Markdown shortcuts off).
- `SyntaxTokenizer`: `Mode.Latex` for language `tex`/`latex` (`Latex`, `ControlEnd`, `units` set); `SyntaxState.TexMath` new member.
	- Control sequences → Keyword; `%` to end of line → Comment (not `\%`).
	- Math `$…$`, `$$…$$`, `\(…\)`, `\[…\]` → String; `TexMath` carries across lines and closes on the next `$`, `\)` or `\]`.
	- Numbers not preceded by a letter, plus a TeX unit (`pt pc in cm mm bp dd cc sp em ex mu fil fill filll`) → Number.
- Thorium `VaultBrowserControl` unchanged: `Accepts` asks `FileTypes` (was `RichTextDocument.extensions`), `BuildTab` takes any note path.
- New namespace `ArctisAurora.Core.Tex`, pure CPU, nothing in the UI calls it yet:
	- `TexCatcode` — the 16 categories in `\catcode` order. `TexToken` (readonly struct) — `name` (control sequence) or `ch` + `cat`, `param` (1–9 body slot), `line`, `column`. `TexError` — line, column, message.
	- `TexReader` (internal) — TeX's mouth: lines split on `\n`, trailing spaces cut, `\r` end-of-line char appended; states NewLine/MidLine/SkipBlanks; a control word skips spaces after it; a blank line is `\par`; `%` drops the rest of the line; categories are read live, so `\catcode` takes effect mid-line.
	- `TexExpander(string source)`, `errors`, `Next(out TexToken)` — returns the next unexpandable token for a typesetter (characters, `{`/`}` after their group is opened/closed, `\relax`, `\par`).
- Expander coverage:
	- Groups and save stack with TeX's global/local level rule (a global change survives the group's restore); `\global`, `\long`; `\begingroup`/`\endgroup`.
	- `\def \gdef \edef \xdef` with delimited parameters and brace stripping; `\let`, `\futurelet`; `\expandafter`, `\noexpand`, `\csname`/`\endcsname`, `\string`, `\the`.
	- `\if \ifx \ifcat \ifnum \ifdim \ifodd \ifcase \iftrue \iffalse \ifdefined \ifcsname \else \or \fi`.
	- Count/dimen/skip/toks registers, `\chardef \countdef \dimendef \skipdef \toksdef`, `\advance \multiply \divide`, `\catcode`.
	- Numbers by tex.web's scan_int (`'` octal, `"` hex, `` ` `` char code); dimensions by tex.web's scan_dimen arithmetic in scaled points (round_decimals, xn_over_d, units `pt in pc cm mm bp dd cc sp true`, internal quantities as units, `fil`/`fill`/`filll` in glue); `\the` prints via print_scaled. `em` = 10pt and `ex` = 4.30554pt (cmr10), fixed unless `quad`/`xHeight` are set (L3).
	- LaTeX level natively: `\newcommand`/`\renewcommand`/`\providecommand` (star = not long, `[n][default]`), `\newenvironment`/`\renewenvironment`, `\begin`/`\end` (an environment group; mismatched `\end` reported LaTeX-style), `\makeatletter`/`\makeatother`, `\@ifnextchar`, `\@ifstar`, `\newif`, `\newcounter` (global, registers from 256; `[within]` resets x, cascading, when within steps — L3), `\setcounter`, `\addtocounter`, `\value`.
- Errors are collected, never thrown. Recovery is TeX-style: undefined cs skipped, runaway argument stops at `\par` for non-long, a missing `}` reported at end of file, open groups/conditionals reported at end. 1,000,000 expansion steps or input-stack depth 10,000 halts the run with an error.
- Tests: engine suite `Tex.tests.axml` (`TexTests`) — `Tex.SourceRoundTrip`, `Tex.Catcodes`, `Tex.DelimitedDef`, `Tex.ExpandAfter`, `Tex.Edef`, `Tex.Groups`, `Tex.Conditionals`, `Tex.Registers`, `Tex.NewCommand`, `Tex.NewEnvironment`, `Tex.Errors`; `Syntax.Latex` in the Syntax suite; Thorium TextInput suite `Tex.SourceEnterPaste`, `Tex.SourceColours` (golden `Tex.SourceColours.Source.png`).

## Why these choices

**The whole LaTeX editor is native, not a port of tex.web.** (agreed with the user 2026-10-05)
A full port (TRIP-verified, XeTeX-compatible, running the real `latex.ltx` and package `.sty` sources, Aurora only rendering shipped pages) was considered and rejected by the user. It would run any package's source but costs the port's T3–T5 (~25k lines of WEB) before anything shows; native gets the user's documents sooner and reuses Aurora's runs, `TextMeasurer`, `Paginate` and math. Cost accepted: support is bounded by what we reimplement — every package environment (amsmath `align` two-pass, `tabular`, …) is C#, and a package we have not rewritten (e.g. `mathtools` patching amsmath internals) does not work. The analysis behind the choice: Aurora's typesetting cannot run TeX macro code that reads layout mid-expansion (`\lastskip`, `\wd` of a just-built box, `\pagetotal`, `\output`), because `DocumentControl.Paginate` is a post-measure placement pass and `TextLine` is float geometry with no glue. The drawing layer is reusable either way.

**L-F1: no NuGet, no external tools.** `\usepackage` is accepted; unknown packages are logged and ignored. Package set is "as many as possible" (user), starting from amsmath, amssymb, graphicx, xcolor, hyperref (links), geometry, booktabs, enumitem, fancyhdr and growing. L9 adds titlesec, ulem, mathptmx/times/tgtermes/newtxtext. L10c adds fontspec.

**L-F2 level 2: a real TeX tokenizer + expander, document commands and package environments as C# primitives.**
Rejected level 1 (a command table with template `\newcommand`): it breaks on `\def\foo#1.#2`, `\expandafter`, `\newif` and `\makeatletter` code.

**L3 emits a TeX-like node list (chars, glue, kerns, penalties, boxes), lowered to `<Document>` afterwards.** (user: "your recommendation")
It keeps `\hbox`/`\setbox`/`\wd`, `\vskip`, `\lastskip`/`\unskip`/`\lastbox` addable later; emitting straight to `<Document>` closes them. `\output` and the page-builder primitives stay out — that is the port route.

**L-F3 / L-F4 / L-F5 / L-F6.** Overleaf-style split view (source + read-only paged preview). The preview is the `<Document>` tree, Aurora's layout gaining glue gaps, a Knuth-Plass mode, hyphenation, footnotes, running heads and float placement in L7. CFF (Type 2 charstrings) font support is added — the atlas baker already takes cubic `Bezier` contours (`SvgPath` feeds cubics to the MTSDF generator), so the work is the CFF table reader. Endnotes in v1, real footnotes in L7. Superseded by L7e (2026-10-06): real footnotes at the page foot; the endnote section is gone.

**The file/editor and the expander were planned as two phases and merged into L1** (user).

**`.tex` reuses `DocumentEditorControl` instead of a new editor control, each source line a Code block.** Undo, selection, clipboard and code colouring come with it.

**Line ending and BOM live on `RichTextDocument`**, so a save is byte-identical; precedent `SheetDocument.csvBom`. `.txt` is deliberately not changed.

**The expander has its own namespace `ArctisAurora.Core.Tex`** (pure, no UI dependency) rather than sitting flat in `Core.UI` like `MathParser`.

**Meanings are nested private types inside `TexExpander`** (Primitive/Macro/CharMeaning/Register) with one generic save-stack `Table<TKey,TValue>` for meanings, catcodes and registers. `\begin`/`\end` close the environment group through an internal sentinel control sequence pushed after `\end<name>`'s code.

**`DocumentControl.EndCodeBlock` is off in `plainText`** (user, 2026-10-05): Enter on an empty last code line would turn it into text, so a `.tex` would lose its LaTeX lines while typing at the end. `Tex.SourceEnterPaste` covers it.

**`.tex` shares the `.txt` refusals** (user, 2026-10-05) — `DocumentEditorControl.CanAlign`, `InsertTable`, `PasteImage`: a table, picture or alignment has nowhere to go in source. No test.

**Latin Modern ships as a baked atlas only** (user, 2026-10-05) — SUPERSEDED by L8-F2 (2026-10-07): the `.otf` files are now committed beside their atlases in Thorium's `Data/Fonts` because the PDF export draws from the outlines. Originally: the `.otf` files are downloaded to bake from, not committed and not needed on users' machines; the atlas is what the repo carries.
Fonts bake only in Debug (`AssetImporter`: `if (!Engine.isDebug) return true;`), and a Debug machine without the source logs a Warn and keeps the committed atlas, so committing just the atlas already works. Rejected: committing the `.otf` files (users do not need them) — reversed by L8-F2.

**Empty-glyph fix** (user approved). The old check treated `glyphHeight == 1` / `glyphWidth == 1` (the `Glyph()` placeholder) as "empty"; LM Math's ∑ (−250…750) and √ (−960…40) are exactly 1000 units = 1 em tall, got squashed to 0.1 em and drew as a few dots. Cambria's never hit it. Now "empty" means no contours. Existing atlases are unchanged until re-baked; empty glyphs (spaces) behave as before.

**A C# primitive or a prelude macro: anything `MathParser` also knows (`\,`, `\quad`, `\ldots`, `\{`) must be a caller primitive.** Inside math the typesetter writes tokens back as source with expansion on, so a macro would expand to `\kern…` and break the formula. Text symbols, accents and spacing are therefore C# tables in `TexTypesetter`.

**Math is collected as source text with `passUndefined` on.** User macros expand and unknown commands (`\frac`, `\alpha`) pass through to `MathParser`; a control word gets a trailing space. `\par`, an `\end…` or an internal `@end…` sentinel inside math ends it with "Missing $ inserted".

**Typesetter state is saved through the expander's save stack via `Save(Action)`**, so `{\bf x}` and environments restore as TeX does. Headings and footnotes suspend/resume the outer state through an internal frame stack, ended by sentinels `\@endhead`, `\@endnote`; `\@runin` (run-in `\paragraph`) and `\@label` (`\item[x]`) skip the following space. Alignment is taken when a paragraph ends (TeX's rule), so `{\centering text\par}` centres and `{\centering text}` does not.

**Ligatures live in the typesetter, Roman/Sans only:** `` `` `` → “, `''` → ”, ` → ‘, ' → ’, `--` → –, `---` → —, `!``/`?`` → ¡/¿, ff fi fl ffi ffl → U+FB00–FB04; braces break a ligature; none in mono. **Accents compose with Unicode NFC** (base + combining mark); `\i`/`\j` as accent bases become i/j; an accent over nothing gives the spacing accent; no precomposed form → base letter + Warn.

**A fragment with no `\documentclass` is typeset as a body** (lenient; tests use fragments). Text in the preamble is "Missing \begin{document}" once. Nothing after `\end{document}` is read.

**L6: equation numbering is source rewriting.**
The typesetter splits the collected body into rows at top-level `\\` (outside braces and nested `\begin…\end`). Each numbered row gets an injected `\tag{n}`, and its `\label` maps to n, or to the tag's text when a `\tag` is present. `equation` and `multline` take one number, `multline`'s on the last row. `\notag`/`\nonumber` and empty rows are not numbered. Numbers are `n` in article and `chapter.n` in report/book, like figures. The body is wrapped in `\begin{env}…\end{env}`, except `equation`. `MathParser` therefore never auto-numbers, so notes do not number either (as in Obsidian; only `\tag` shows).

**L7b: word rules are TeX-like.**
A word is a run of letters in one style, not monospaced (TeX's `\hyphenchar` -1 for tt). Letters a-z, capitals lowered, ligatures ﬀ ﬁ ﬂ ﬃ ﬄ taken apart for lookup with no break inside a ligature. Minimums 2 and 3 come from the file and apply to exceptions too. `\hyphenation` beats the file's exceptions, which beat patterns. Headings are hyphenated as in LaTeX; code is not.

**L7b: U+00AD is general in Aurora.**

**L7b: Knuth-Plass hyphen costs are TeX plain's.**

**L7c: indent rules.**
A paragraph is indented by `\parindent` (15/17/18pt) unless `\noindent`, right after a heading (until text), right after a list/trivlist environment or float until a blank line, inside a list or quote, or not justified (centred/flush/ragged paragraphs, LaTeX's `\parindent` 0 there); `\bibitem` entries never.

**L7c: list skips and `BlockSpacing`.**
`\topsep` above and below, `\itemsep + \parsep` between items, `\parsep` between paragraphs of one item; second level half, deeper a quarter (approximates `\@listii`/`\@listiii`). `BlockSpacing` is 0 for LaTeX documents, which is `\parskip` 0pt.

**L7-F1 edit rules (user, asked mid-implementation).**

Rejected: deleting a footnote with its anchor in one undo step (range delete and undo would have to learn about groups); a paste that carries nothing.

**L7g: amsmath's spacing, verified against `amsmath.dtx` (latex3/latex2e on GitHub, `\measure@` and `\multline@`).**
`align` with n pairs: the margins and the pair gaps are all (W − Σ columns) / (n + 1). `flalign`: no margins, gaps (W − Σ) / (n − 1), one pair falls back to `align`; gaps are at least `\minalignsep` (10 pt = 1 em), the margins then take (W − Σ − (n − 1) · sep) / 2, never negative. `multline`: the first row is `\multlinegap` (1 em) from the left, the last row `\multlinegap` from the right (with a tag, the tag and `\multlinetaggap` instead), middle rows centred. `alignat`, `aligned` and `gather` are unchanged.

**L7g: a table takes its alignment when the paragraph holding the tabular ends.**
That is TeX's rule, as for text: `{\centering\begin{tabular}…\end{tabular}}` followed by a blank line stays left.

**L7g supersedes L5-F2 and resolves L6-F1 partly.**
LaTeX tables are always `Borders="false"` with exact rules. L6-F1's "L7 could revisit" is done for top-level `align`/`flalign`/`multline`; L6-F2 partly (the tag room is now amsmath-like, a tag still never moves to its own line).

**L7e: footnotes stay in the flow lists but are not in the flow.**
Footnotes and floats stay in `children` and `document.blocks` in source order, so measuring, `Blocks()`, click-to-source and `blockLines` line up. The flow loops skip them (`Paginate`, `ArrangeCore`'s block loop, `MeasureCore`'s from/to count, `CollectChildren`'s binary search) and they are placed from `insertControls`; `blockTops` stays monotonic. `PageSpace` is used only when the document has inserts, so plain notes take the unchanged `PageBands.Push` path (one null check per line added in `TextRunControl.Paginate`). A footnote taller than its page's text area starts below the last text on that page (`PageSpace.TextEnd`) instead of rising above it — found by a test where a 405 px footnote on a 367 px text area overlapped the previous page. A LaTeX footnote's id is its sequence number, not the counter, so `\setcounter{footnote}` cannot make two footnotes share an id.

**L7d: marks follow TeX per page.**
`\leftmark` is the left half of the page's last mark, `\rightmark` the right half of its first mark, carried from earlier pages when the page has none. `\markright` keeps the left half. Heading marks follow the article/report/book one-sided rules; starred headings set none.

**L7d: default page style and geometry.**
Plain for article and report, headings for book; `\maketitle`'s page takes plain. Every LaTeX preview now shows a page number in the foot. A head slot's bottom is `HeadSep` (25pt = 8.8 mm) above the text top; a foot slot's bottom is `FootSkip` (30pt ≈ 10.5 mm) below the text bottom; fancyhdr's `\headrulewidth` default 0.4pt is drawn under the head. The footnote rule is 0.4pt × 0.4 text width, 2.6pt above the first footnote; `\skip\footins` is 9/10/10.8pt by class size.

### Why these choices

**L11e-F1 (user: a): every vertical glue the typesetter writes that LaTeX defines as glue carries shrink.** `\parskip`, `\parsep`/`\itemsep`, `\topsep`, `\partopsep`, display skips, default `\@startsection` skips, `\vskip`/`\vspace` minus. Rejected (b), only lists and displays (what the measured pages use): a partial set would pick wrong breaks elsewhere. Left rigid: float separations (L11d), enumitem key values, titlesec spacing. Depth-2+ list shrink is the outer value halved/quartered like the widths (LaTeX's \@listii/iii shrink is ~1pt) — an approximation.

**L11e-F2 (user: a): greedy page fit counting shrink.** A span fits while its natural bottom minus the page's gap shrink so far is inside the text area; when content leaves a page that overflowed, ratio = overflow ÷ page shrink (≤ 1), the page is rolled back and laid out again with each gap reduced by ratio × its shrink and no slack. Rejected (b), TeX's full page-builder cost model (badness from stretch/shrink totals + penalties: −51 list items, 150 club/widow, −300 before a section): it would replace the widow rule and KeepWithNext with penalties and could change note pagination. Background: the thesis is oneside article = \raggedbottom, yet TeX still shrinks on overfull pages because an earlier break with little finite stretch costs ~100000 (deplorable); pages are never visibly stretched (\@textbottom's fil). This is the user's "two-pass page builder" idea, done per page rather than per document (a document-level second pass would squeeze pages broken in the wrong places).

**Keep-run interplay (found in implementation).** A keep rewind sets the page's fitted end back to the block before the moved run (`TakeBack`); if that page overflows it is shrunk and the run is forced to the next page top (`forcedBreak`). A shrink re-layout that starts at or passes a block a keep rewind moved re-applies that forced break — without it the heading "2.5.5 WebGL API" fell back to the bottom of thesis p13.

**L11e-F3 (user: a): URL stretch as run attributes (`UrlStretch` px, penalties) on the URL's run.** Rejected (b), a zero-width marker between every URL character: it doubles URL text and touches caret, selection and the PDF text layer.

**L11e-F4 (user: b): biblatex's break set and penalties too, not stretch only.** Values read from biblatex.def (plk/biblatex): `\biburlbigskip = 0mu plus 3mu`, `\Urlmuskip\biburlbigskip` in `\biburlsetup`, `biburlbigbreakpenalty 100`, `biburlbreakpenalty 200`, `\UrlBigBreaks{\do\:\do\-}`, the ordinary set above; num/uc/lc penalties 0 = no extra breaks. Two new markers U+E005/U+E006 (precedent: U+E001–E004 space-factor markers, L10f-F6 U+200B). Constants live in the bibliography driver (our expander has no biblatex counters; the thesis sets none). Plain `\url` keeps url.sty-like free U+200B breaks; url.sty's own default penalties (`\binoppenalty`) are left out. The greedy fallback (no feasible Knuth-Plass set) ignores penalties. Reverses L10f-F6's rejection of `\Urlmuskip` stretch.

**Consequence of the pixel weights.** `Spread` switched to pixel weights so URL gaps and spaces share one unit; justified note lines that mix space widths spread slightly differently now (they match the breaker). Stretch no longer goes to rigid spacer runs in caret math (it never did in drawing).
